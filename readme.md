## Catalogo de productos
Aplicación web orientada a una vista simple de productos ofrecidos por una tienda. Sirve como punto de acceso para posibles clientes, y como orientación para eventuales solicitudes de cotizacion (cuando corresponda).

## Tecnologías
- HTML
- CSS
- JS
- JSON (fuente de datos para alimentar vista)
- GIT/Github
- Deploy con GitHub Pages

## Flujo de aplicación
- Se cargan datos desde archivo JSON
- Datos son almacenados en memoria
- Se renderizan en el DOM
- Son agrupados por categorías (en desarrollo)
